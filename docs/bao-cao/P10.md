**Cập nhật native sau báo cáo này:** xem [P15-native](P15-native.md). Bản sửa tiến độ 787e3d1 có 113 PASS/0 FAIL/4 SKIP; bằng chứng D54 và 667 được tách rõ, không dùng mô tả chờ desktop ở mốc cũ làm trạng thái hiện hành.

Tiếp tục P11–P15 độc lập theo yêu cầu làm toàn bộ.

## Đầu ra thực

Export có sheet AppKit với preview checkerboard, PNG/JPEG, kích thước liên kết mặc định, PPI theo locale, alpha PNG, JPEG quality 1–100 và matte trắng/chọn màu đặc. Preview và file dùng chung renderer toàn layer hiển thị; file cuối render ở kích thước yêu cầu. SavePanel native chọn vị trí và xác nhận overwrite. Tác vụ nền có progress/Cancel; atomic write cùng thư mục giữ file cũ nếu lỗi/cancel trước rename. Export giữ nguyên model, source bytes, history, URL và saved marker.

Image I/O nhận CGImage mới với metadata whitelist PPI/orientation/quality. Không chuyển EXIF/GPS nguồn. `ICCEmbedding` thêm actual ICC sRGB từ ColorSync: iCCP PNG và APP2 JPEG, vì named color space của Image I/O có thể chỉ ghi sRGB tag. Matte được composite trong linear sRGB trước encode RGBA8. HDR/gain-map và high-depth được nhập về SDR; nguồn nhúng vẫn bất biến. Save/Open HDR giữ cờ chuyển SDR.

## Nguồn kỹ thuật

Metadata theo [Apple Image properties](https://developer.apple.com/documentation/imageio/image-properties); actual profile theo [PNG iCCP](https://www.w3.org/TR/png-3/#11iCCP) và [ICC specifications](https://www.color.org/icc_specs2/). HDR fixture dùng [Image I/O ISO HDR encoding](https://developer.apple.com/documentation/imageio/kcgimagedestinationencodetoisohdr). Không thêm SDK/codec/telemetry bên ngoài.
