   manual adaptive inspector rows; final test runtimeWarnings=[]; VI/EN layout test passes.

   committed/discarded. End field editing via canvas focus first, then Apply/Cancel.
   Hosted regression checks session=nil, history count and restored size.
3. Invalid font size was forwarded to NSTextView. Use the candidate's last validated style and
   extent for the editor while invalid draft controls remain visible and Apply is disabled.
   Regression uses 1e100; observed native validation at 1001. No huge editor layout now.
4. Increased Alpha % label width; final VI/EN label is fully visible.
