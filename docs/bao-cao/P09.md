# P09 — PhotoAxis Document, Save/Open an toàn

**DONE — 02/10/2026**, baseline 1.0-draft.3, app 1.0.0 (1). Chặng triển khai local; không push/public. P06 vẫn BLOCKED_EXTERNAL ở Telex/VNI A22. A20 và A43 còn bước Export P10.

## Kết quả

`.paxis` là một ZIP32 với JSON schema 1, original image bytes deduplicate theo SHA-256 và preview PNG. Model giữ UUID/order/Unicode, canvas/PPI, typed text/font/shape, matrix Double/clip, visibility/lock/opacity và Image Adjustments. Reader kiểm metadata, quotas, CRC/hash/header/entry path, phiên bản và payload; không extract đường dẫn ra disk. Định dạng và giới hạn cụ thể: [DINH_DANG_PAXIS](../DINH_DANG_PAXIS.md). Nguồn và clip theo hợp đồng P07/P08, không flatten tài liệu.

Save/Save As native qua NSSavePanel, snapshot trên main actor và worker ghi streaming vào temp cùng thư mục, synchronize rồi atomic rename. Hủy/lỗi trước điểm commit giữ bản cũ. Saved marker dùng stateID đã ghi; edit sau snapshot vẫn dirty, Undo về snapshot clean. Menu Cmd+S/Shift+Cmd+S, Save khi đóng và application open-URLs/Finder dùng cùng coordinator; NSDocument vẫn sở hữu Undo/dirty state. Đóng/mở không nạp lại Undo cũ. Chọn Save As có overwrite confirmation native.
