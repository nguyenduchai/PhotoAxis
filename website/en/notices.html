Components and notices

The app uses Apple system frameworks: AppKit/Foundation, MetalKit/Core Image/Core Graphics/Image I/O/Core Text/ColorSync and system zlib for ZIP/CRC. No third-party package or font file is bundled.

PhotoAxis app/tool icons are authored as project code. Demo content uses synthetic geometry/color/text fixtures. Perspective screenshots capture the historical baseline build1 Release in Vietnamese/English; recovery screenshots capture actual native startup from the same historical baseline build1 Release. Adobe reference images, Photoshop logos, stock content and web mockups are excluded from distribution assets.

Apple frameworks follow Apple SDK terms; see the zlib license. PhotoAxis source is licensed under GNU GPL version 3 (GPL-3.0-only); see LICENSE in the repository. External frameworks retain their respective terms. Build/test tools are not bundled in the app.
