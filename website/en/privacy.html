PhotoAxis 1.0.0

Privacy

App data

PhotoAxis processes images offline, without accounts, telemetry, cloud sync, advertising, AI services or its own automatic updater. Projects and exports stay where you save them. Settings and recovery use local application storage.

Embedded sources and metadata

.paxis preserves original source bytes, including possible EXIF/GPS and cropped-out content. A crop clip does not remove source bytes from the project. Share a project only when you intend to share all embedded sources. Fresh PNG/JPEG export removes original GPS/metadata; it does not certify that visible sensitive information has been redacted.

Recovery

Recovery is a local self-contained project. Save and Don’t Save clean matching records according to the document lifecycle. Draft sessions are not promised recoverable. PhotoAxis does not sync recovery to a cloud service.

Website and downloads

This static preview has no analytics, cookies, account form, font CDN or trackers. This site is hosted on GitHub Pages. GitHub may process IP addresses and access logs under its privacy statement. Source and public issues are hosted on GitHub; do not upload sensitive case data.

Investigation data

.paxcase, analysis JSON and processing logs may include unredacted originals, metadata, OCR text, video frames and measurement records. They are not redacted sharing copies. OCR uses Apple Vision locally; it does not reconstruct missing text or use an external AI service. Reviewed PNG/A4-PDF sharing is separate.
