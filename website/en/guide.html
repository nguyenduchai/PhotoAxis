PhotoAxis 1.0.0

User guide

Build from source

The source, tests and this website share one public repository. License: GNU GPL version 3 (GPL-3.0-only). With an Apple Silicon Mac and Xcode installed, clone the repository, run ./scripts/build.sh Release, or open PhotoAxis.xcodeproj. See build instructions for requirements and output paths. Self-built and local ad-hoc builds are not notarized releases.

Install and open

The public installer is not released yet. Once a signed, notarized DMG is available, download the versioned asset and checksum, open it and drag PhotoAxis to Applications. Use normal Gatekeeper checks. Do not disable Gatekeeper or remove quarantine. If the developer cannot be verified, stop and contact the published support channel.

Language and documents

Settings offers System Default, Tiếng Việt and English; changes apply on the next launch. Numbers and dates follow the macOS region. Layer names and text do not change with the interface. New creates a preset/custom canvas with background and PPI. Open accepts static PNG/JPEG/HEIC or .paxis. Oversized inputs require a resize choice or cancellation.

Layers and tools

Place/drag/paste adds images according to context. Select one layer, rename/reorder/hide/lock/change opacity/duplicate/delete it. A locked layer can be selected but not directly edited. Move/Transform has a preview session: Apply creates one Undo step, Cancel discards the draft. Crop supports Free/Ratio/W×H; Image Size/Canvas Size/rotate/flip operate on the document.

Perspective Crop

  1. Choose Perspective Crop and place TL/TR/BR/BL around the retained region, using pan/zoom for accuracy.
  2. Choose Auto, Ratio or W×H; inspect grid/Preview and dimensions. Invalid or oversized quadrilaterals cannot Apply.
  3. Apply maps every existing layer, including hidden/locked layers, to the corrected canvas and clip. Layer types and source bytes remain editable; Undo/Redo restores the document.
  4. New text uses the corrected canvas. Edit older projective text through Properties to preserve its mapping and clip. Cropped-out source content remains embedded but is clipped from output.

Text, shapes and color

Type supports multiple lines: Return adds a line, Cmd+Return applies and Escape cancels. Actual Telex/VNI acceptance is pending. Rectangle/Ellipse/Line have fill/stroke; HEX/RGB and Eyedropper use the image composite without overlays. Missing fonts are substituted with a warning, while the original font name is preserved. The fallback can look different; font files are not embedded.

Exposure/Brightness/Contrast/Saturation belong to image layers, with enable/reset/Undo. Preview drags commit one command and do not overwrite source images.

Save versus Export

Save/Save As .paxis creates a self-contained ZIP with original source bytes, typed layers, matrices/clips/parameters and preview. Moving the project does not require the original input paths. History is session-only and starts empty after reopening.

Export PNG/JPEG flattens visible layers as 8-bit sRGB at the chosen size/PPI. PNG can retain alpha; JPEG uses an opaque matte (white by default) and quality1–100. Export removes original GPS/metadata and leaves the project dirty state intact. Saving .paxis keeps original metadata, including GPS.

Recovery and closing

Recovery periodically stores committed edits. Only a completed recovery write is a recovery point; an uncommitted crop/text/transform draft is not promised. After an abnormal stop, open or discard the available recovery. Recovered documents open unsaved for Save As. Save clears the matching saved state; Don’t Save clears closed documents, while Cancel preserves tabs/recoveries. Failed/incomplete writes are not guaranteed recoverable.

Limits

Apple Silicon/macOS14+ is the support target; macOS14/1× hardware verification is pending. Limits:8000px/edge,40MP per canvas/source,50layers,120MP unique sources/document,5tabs,100steps/128MiB History. Normal blend, single layer selection. No PSD/RAW/Mask/AI/Intel/App Store. Maximum quota combinations do not promise basic-document performance.

PhotoAxis 1.0.0 · build 8

Analyze the open image directly

Analysis and Output follow the active tab. Ordinary images can use OCR, annotations, before/after comparison, calibrated measurement, redaction and sharing exports immediately. The local analysis uses a rendered snapshot of the committed canvas; save it as a case to retain results. Received originals use the separate Sources intake workflow. Editing changes invalidate old calibration and redaction review.

Cursors identify the selected tool

Native cursors follow Crop, perspective, Move, Brush, Clone, Eyedropper, text, shapes and Zoom. Handles show resize or rotation; Hand opens and closes while dragging. Option changes Zoom to minus and Clone to sampling; Space temporarily pans.

PhotoAxis 1.0.0 · build 7

Readable rulers and useful Settings

Horizontal and vertical rulers share the canvas origin, use readable horizontal numbers and keep each label inside its bounds. Choose px, mm, cm or inches in Settings; print units follow document PPI. Settings now has General, Workspace, Canvas and Default Brush sections, with saved preferences for panel width, rulers, canvas background, transparency grid and the defaults used by newly opened documents.

Investigation in the same workspace

The right panel now shows four persistent buttons: Edit, Sources, Analysis and Output. To preserve received originals, use Sources to create or open a case, intake an image and select its working document. Edit uses the ordinary canvas tools. Analysis contains annotations, OCR, video frames, calibrated measurement and comparison; Output contains review and separate sharing exports. Calibration is needed to measure objects in an image; print ruler units alone are not calibration.

PhotoAxis 1.0.0 · build 6

Live previews, Brush and Clone Stamp

Scan controls refresh the before/after result automatically. Crop and Perspective Crop show a live result inset while you adjust the corners. Image and Canvas Size refresh while typing; image adjustment sliders already preview continuously. Brush (B) draws on an editable paint layer with size, hardness, opacity and foreground color; Clone Stamp (S) samples the visible composite with Option-click and preserves a frozen sample. Aligned and unaligned strokes are supported. Release the pointer to commit one Undo step; Escape cancels the current stroke. Projects with paint use schema4 and include clone samples. Source originals remain intact.

PhotoAxis 1.0.0 · build 5

One workspace for editing and analysis

Sources, Analysis and Output sit beside Edit in the native sidebar. Case intake, annotations, Vietnamese OCR, video frames, calibrated measurements and reviewed exports share the editor. Comparisons and source review use the canvas; pick regions and ordered points directly on the image, then Apply or Cancel. No separate Investigation menu or window.

PhotoAxis 1.0.0 · build 4

Clean and standardize document scans

Detect page corners and text angle; whiten paper, reduce shadows/noise and use adaptive black and white. Manual two-axis page-bow correction and A4/Letter/custom size. Batch up to 50 images with ordered PNG, editable projects, PDF and a hash manifest. Review every page; real camera/book and maximum-quota qualification is pending.
