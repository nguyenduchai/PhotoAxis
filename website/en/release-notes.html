PhotoAxis 1.0.0

Release notes

Version1.0.0(9) is in preparation. No public installer is available yet.

Implemented in the development build

  • Native Vietnamese/English workspace, tabs, Layers/Move/Transform/History.
  • Crop/size/rotate/flip and document-wide editable Perspective Crop for images/text/shapes.
  • Type/Rectangle/Ellipse/Line/Color/Eyedropper and per-image adjustments.
  • Self-contained .paxis schema1, safe Save/Open and sRGB PNG/JPEG with alpha/matte/quality/size/PPI.
  • Committed-edit recovery and multi-document close/quit preflight.

Pending acceptance

Real Telex/VNI, remaining native shortcut/layout/background-task checks, macOS14/non-Retina/reference machines and clean signed/offline installation remain pending. Worker performance was measured on M1 Pro32GB/macOS27; native FPS and other machines are not certified. Metal/QoS warnings are under investigation. Final details will be settled before publication.

Requirements and limitations

Target Apple Silicon/macOS14+; no Intel/App Store. No PSD/RAW/Mask/AI. Session-only history; fonts are not embedded. Save preserves original bytes/GPS in .paxis; Export removes source GPS metadata.

PhotoAxis 1.0.0 · build 9

Native Preferences, light or dark

Preferences now uses a category sidebar and grouped controls: General, Interface, Workspace, Canvas, Brush Defaults and File Handling. Choose Dark, Light or Use System; the theme applies immediately to native windows, panels and dialogs.

Set the brush size outline, recovery interval (10/30/60 seconds), default PNG/JPEG format, JPEG quality and linked export dimensions. Valid choices are saved automatically. Language takes effect after restarting.

Cancel text recognition

Analysis offers Cancel text recognition while Vision runs. Cancellation restores the workspace and discards late results without writing unfinished OCR into the audit log. An OS worker still stopping blocks another OCR worker; image editing remains available.

Whole automated suite: 209 tests, 205 passed, one known synthetic Telex failure and three opt-in benchmarks skipped in the default run. Separate benchmark and native verification are documented in the build 9 report. These checks do not replace full target hardware, IME or installer acceptance.

PhotoAxis 1.0.0 · build 8

Analyze the open image directly

Analysis and Output follow the active tab. Ordinary images can use OCR, annotations, before/after comparison, calibrated measurement, redaction and sharing exports immediately. The local analysis uses a rendered snapshot of the committed canvas; save it as a case to retain results. Received originals use the separate Sources intake workflow. Editing changes invalidate old calibration and redaction review.

Cursors identify the selected tool

Native cursors follow Crop, perspective, Move, Brush, Clone, Eyedropper, text, shapes and Zoom. Handles show resize or rotation; Hand opens and closes while dragging. Option changes Zoom to minus and Clone to sampling; Space temporarily pans.

Open-image analysis and cursor guide

PhotoAxis 1.0.0 · build 7

Readable rulers and useful Settings

Horizontal and vertical rulers share the canvas origin, use readable horizontal numbers and keep each label inside its bounds. Choose px, mm, cm or inches in Settings; print units follow document PPI. Settings now has General, Workspace, Canvas and Default Brush sections, with saved preferences for panel width, rulers, canvas background, transparency grid and the defaults used by newly opened documents.

Investigation in the same workspace

The right panel now shows four persistent buttons: Edit, Sources, Analysis and Output. To preserve received originals, use Sources to create or open a case, intake an image and select its working document. Edit uses the ordinary canvas tools. Analysis contains annotations, OCR, video frames, calibrated measurement and comparison; Output contains review and separate sharing exports. Calibration is needed to measure objects in an image; print ruler units alone are not calibration.

Settings guide · Investigation workflow

PhotoAxis 1.0.0 · build 6

Live previews, Brush and Clone Stamp

Scan controls refresh the before/after result automatically. Crop and Perspective Crop show a live result inset while you adjust the corners. Image and Canvas Size refresh while typing; image adjustment sliders already preview continuously. Brush (B) draws on an editable paint layer with size, hardness, opacity and foreground color; Clone Stamp (S) samples the visible composite with Option-click and preserves a frozen sample. Aligned and unaligned strokes are supported. Release the pointer to commit one Undo step; Escape cancels the current stroke. Projects with paint use schema4 and include clone samples. Source originals remain intact.

PhotoAxis 1.0.0 · build 5

One workspace for editing and analysis

Sources, Analysis and Output sit beside Edit in the native sidebar. Case intake, annotations, Vietnamese OCR, video frames, calibrated measurements and reviewed exports share the editor. Comparisons and source review use the canvas; pick regions and ordered points directly on the image, then Apply or Cancel. No separate Investigation menu or window.

PhotoAxis 1.0.0 · build 4

Clean and standardize document scans

Detect page corners and text angle; whiten paper, reduce shadows/noise and use adaptive black and white. Manual two-axis page-bow correction and A4/Letter/custom size. Batch up to 50 images with ordered PNG, editable projects, PDF and a hash manifest. Review every page; real camera/book and maximum-quota qualification is pending.
